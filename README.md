# antonkim.com

Личная страница-визитка: фото, имя и ссылки на площадки. Статика — ни сборки,
ни зависимостей, ни скриптов на странице.

## Структура

```
├─ index.html     вся разметка
├─ styles.css     стили
├─ make_photo.py  пересборка картинок из исходного выреза
├─ img/           аватар в двух размерах (webp) и фавиконки
└─ fonts/         Inter 400/700/900, кириллица и латиница отдельными файлами
```

## Посмотреть локально

```
python -m http.server 8000 --directory .
```

и открыть `http://localhost:8000/`.

## Что где менять

- **Ссылки и подписи** — блок `<ul class="places__list">` в `index.html`.
  Один `<li>` = одна строка на странице, порядок в разметке = порядок на экране.
- **Имя и строчка под ним** — `<h1 class="name">` и `<p class="lead">`.
- **Цвета и размеры** — блок `:root` в `styles.css`.
- **Фото** — положить новый вырез на прозрачном фоне и прогнать
  `python make_photo.py путь_к_файлу`. Скрипт обрежет по краям картинки, впишет
  голову в кадр и разложит по размерам. Круг рисует CSS, а не картинка.

## Что лучше не ломать

- **Файл `CNAME`** — по нему привязывается домен. Удалить или переименовать
  значит отвязать.
- **Шрифты лежат локально**, подмножествами с `unicode-range`: браузер тянет
  только нужный алфавит. Менять на внешнюю ссылку не надо.
- **Подложка круга светлая**, хотя страница чёрная: вырез снят на светлом фоне,
  на тёмной подложке волосы сливаются с фоном.
- **`target="_blank"` и скрытая приписка «откроется в новой вкладке»** живут
  в паре. Убираешь одно — убирай и другое, иначе экранная читалка промолчит
  о смене контекста.
- **У фото `alt=""`** намеренно: сразу под ним заголовком идёт имя, описательный
  alt дал бы читалке дубль.
- **У иконки Lichess `stroke-width="2.2"`** — их логотип нарисован линией, а не
  залит, и с родной толщиной на 22 px выглядит бледной паутинкой.
